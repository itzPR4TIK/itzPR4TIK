## About Me

I am **Pratik Nagpure**, a full stack developer based in Pune, India. I design and build web applications end to end, from responsive React interfaces to secure Node.js services and well-structured relational databases. Alongside my industry work, I am pursuing a Diploma in Artificial Intelligence, which shapes how I approach problem solving, data and automation.

I value precision, clear communication and software that is simple to maintain. I also enjoy teaching, and I mentor engineering interns in Python full stack development.
